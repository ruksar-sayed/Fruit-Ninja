# Fruit Ninja Game

## Project Description
Fruit Ninja is an interactive browser-based game developed using HTML, CSS, and JavaScript. Players slice falling fruits to score points while avoiding bombs. The game provides an entertaining experience and tests the player's reflexes and accuracy.

## Objectives
- Develop an interactive browser game.
- Detect user interactions for slicing fruits.
- Track the player's score.
- Add sound effects and visual animations.
- Make the game easy to play and user-friendly.

## Technologies Used
- **HTML5** — Game structure
- **CSS3** — Styling and animations
- **JavaScript** — Game logic and interactions

## Features
- Interactive fruit-slicing gameplay
- Score tracking
- Bomb avoidance
- Visual effects and sound effects
- Browser-based gameplay

## How to Run
1. Open the project in GitHub Codespaces.
2. Open the terminal.
3. Run `python3 -m http.server 8000`.
4. Open the Ports tab and visit the forwarded port 8000 URL.
